# Module 03 — Lesson 01: Basics and User Input

This lesson covers Python fundamentals focused on user input, string manipulation, and basic calculation logic.

---

## 📁 Files

| File | Description |
|---|---|
| `00_hello_world.py` | First Python program — prints a message to the screen |
| `01_name_length.py` | Reads the user's name and returns the number of characters |
| `02_sum_calculator.py` | Simple sum calculator with user input |
| `03_sum_calculator_refactored.py` | Refactored version of the sum calculator |
| `04_challenge_bonus_calculation.py` | Challenge: bonus calculation based on user data |
| `05_challenge_bonus_calculation_fixed.py` | Fixed version of the bonus calculation challenge |

---

## 🧠 Concepts Covered

- `print()` function for output
- `input()` function for user input
- Variables and data types (`str`, `int`, `float`)
- Type conversion (`int()`, `float()`)
- Basic arithmetic operations
- String formatting with f-strings
- Refactoring best practices

---

## ▶️ How to Run

Make sure you have Python installed (version 3.x recommended).

```bash
python file_name.py
```

Example:

```bash
python 04_challenge_bonus_calculation.py
```
